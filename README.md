# TI-Forge
TI-Forge is an IDE for the TI-BASIC programming language. It is a custom-build Vim clone designed for programming in TI-BASIC.

[Latest Build (.exe)](ti_forge.exe)  
[GNU GPL v3 License](LICENSE)

### Overview
TI-Forge is designed to be an alternative to the usual ways of programming in TI-BASIC, like the calculator or TI Connect CE.

### Features
Blazingly fast  
Cross-platform
Familiar Vim keybindings
